# مشاركة صوت مباشرة بموافقة صريحة

هذا مشروع ويب تجريبي يتيح مشاركة صوت الميكروفون مباشرةً بعد موافقة صاحب الجهاز، وصفحة استماع محمية بكلمة مرور. **ليس آلة حاسبة متنكرة، ولا يبدأ الميكروفون تلقائياً، ولا يخفي مؤشر المشاركة.**

## تشغيل تجريبي على كمبيوتر
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في الطرفية.
3. عيّن كلمة مرور قوية للمستمع (12 حرفاً على الأقل):
   - Linux/macOS: `export LISTENER_PASSWORD='ضع-كلمة-مرور-قوية-هنا'`
   - Windows PowerShell: `$env:LISTENER_PASSWORD='ضع-كلمة-مرور-قوية-هنا'`
4. نفّذ `npm install` ثم `npm start`.
5. افتح `http://localhost:3000` للتجربة على الجهاز نفسه.

## الاستخدام عبر الإنترنت
يلزم نشر المشروع على خدمة تستضيف Node.js مع HTTPS/WSS. المتصفح يشترط عادةً سياقاً آمناً لاستخدام الميكروفون. قد تتطلب بعض الشبكات خادم TURN لإتمام اتصال WebRTC؛ هذا النموذج يستخدم STUN فقط وقد لا يعمل على كل الشبكات.

## تنبيهات قبل النشر الحقيقي
- لا تستخدم كلمة المرور الافتراضية أو تشاركها علناً.
- أضف تحديد محاولات تسجيل الدخول، ومصادقة أقوى، وسياسة خصوصية، وسجلات تدقيق، وإدارة جلسات قبل الاستخدام الفعلي.
- صفحة الاستماع تعرض الأجهزة التي تشارك الصوت؛ يلزم أن يكون لدى صاحب الجهاز علم وموافقة واضحان.
- هذا نموذج أولي، وليس خدمة إنتاجية جاهزة.
